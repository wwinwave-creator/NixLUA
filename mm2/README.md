# Nix LUA · MM2 · 0.2.0

Модульный клиентский проект для Murder Mystery 2. Меню NeverLose/Shitaro-стиля
на основе локальной библиотеки Src3/UI.lua. Проверено компилятором Luau и автоматическими
тестами; в запущенном Roblox пока не проверено.

## Загрузка на GitHub

Загрузи **loader.lua и папку mm2 рядом, в корень репозитория**.
Удобнее взять содержимое папки release/NixLUA-MM2 или распаковать NixLUA-MM2.zip.
Не загружай tools/node_modules, исходную коллекцию Src/Src2/Src3 или конфиги игрока.

Репозиторий должен быть публичным для обычного game:HttpGet без авторизации.
Замени YOUR_NAME/NixLUA своим owner/repository:

```lua
getgenv().NixLUA_Source = {repo = "YOUR_NAME/NixLUA", ref = "main"}
local source = getgenv().NixLUA_Source
loadstring(game:HttpGet("https://raw.githubusercontent.com/" .. source.repo .. "/" .. source.ref .. "/loader.lua"))()
```

`ref` можно заменить полным SHA коммита: тогда все модули загружаются из одной
неизменяемой версии. С `main` загрузка использует текущую ветку; не обновляй файлы
частями во время запуска. Загрузчик сначала скачивает и компилирует все 15 модулей,
затем запускает проект. Отдельные модули не обращаются к внешним HTTP-адресам.
После изменения файлов в GitHub возможна задержка обновления raw-кэша.

## Управление

- Insert: показать/скрыть меню. Клавиша меняется в Settings.
- End: выгрузить Nix LUA и восстановить изменённые свойства.
- ПКМ: удержание aim assist (по умолчанию); включается во вкладке Aim assist.
- Space: bunnyhop при включённой функции и закрытом меню.
- Цвета выбираются через color picker. Включение/выключение функций через бинды
  доступно в контекстном меню элементов исходной UI-библиотеки.

Aim assist не работает при открытом меню или активном текстовом поле.
По умолчанию цель — Murderer, только при наличии Gun, с проверкой видимости.

## Что включено

- Прицеливание через камеру: выбор роли/части тела, радиус, плавность, дистанция,
  проверка видимости, линейное упреждение и круг FOV.
- ESP: рамки, имена, роли, здоровье, дистанция, оружие, скелеты через Motor6D,
  трассеры, стрелки за экраном, Highlight/chams и подсветка выпавшего GunDrop.
- Цвета Murderer/Sheriff/Hero/Innocent/Unknown, панель ролей и уведомления о смене роли.
- World: fullbright, fog/Atmosphere, время суток, ambient, цветокоррекция,
  насыщенность, контраст, tint, bloom, FOV, Black Storm/Roblox Classic skybox.
- Локальный персонаж: trail, China hat, rainbow, self chams, jump pulses и sparkles.
  Эти эффекты локальные, не обещают видимость другим игрокам.
- Движение: WalkSpeed, прыжок с поддержкой JumpPower/JumpHeight, bunnyhop.
- UI: секции в две колонки, поиск библиотеки, обычные dropdown/slider/color picker,
  настройка акцента, конфиги, диагностика и выгрузка.

## Архитектура

```text
loader.lua
mm2/
  init.luau
  core/       Scope, Settings, Config
  games/      Roles, MM2
  ui/         Library, Menu
  visuals/    Draw, HUD
  features/   Aim, ESP, World, Character, Movement
```

Настройки сохраняются в NixLUA/MM2/<имя>.json в рабочей папке исполнителя.
Имена ограничены, версия и типы JSON проверяются, максимальный размер — 64 KB.
Автозагрузки конфига нет; файловые API нужны только кнопкам Save/Load.
Drawing и getgc не требуются. Нужны стандартные клиентские Roblox API и среда,
которая разрешает HttpGet/loadstring для загрузчика.

## Проверка и ограничения

GetPlayerData запрашивается не чаще раза в две секунды, максимум один запрос
одновременно. Через шесть секунд без ответа данные ролей считаются устаревшими;
дальше используется наличие доступных Knife/Gun. Неизвестная роль отображается Unknown.
Имя remote и формат данных взяты из локальных исходников; обновление игры может их изменить.

Не включены silent aim, убийство через remote, wallbang, автоматический фарм,
скинченджер и изменение инвентаря. Движение может корректироваться игровым сервером.
Наличие меню и успешная компиляция не доказывают совместимость с текущей игрой.

Перед использованием проверь меню, цветовые элементы, отображение ролей, смену
раунда/респавн, выключение эффектов, Save/Load и повторный запуск. End должен убрать
GUI/ESP, отключить обработчики и восстановить Lighting/FOV/параметры Humanoid.
Исходный проект и команды тестов находятся в корневом README разработчика.
