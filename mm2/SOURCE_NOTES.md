# Локальные источники Nix LUA MM2

Использована коллекция из Src, Src2 и Src3. Автоматический индекс SOURCE_INDEX.json
содержит SHA256, размеры и признаки 411 Lua/Luau/TXT файлов (324 уникальных содержимых
на момент сборки). Индексация означает поиск по тексту, а не полный аудит каждого файла.
Индекс остаётся локальным и не включается в пакет публикации.

## Меню

ui/Library.luau адаптирован из Src3/UI.lua, библиотеки с внутренним именем NeverLose.
Исходный SHA256: 96237bbaeac8982e09a70dc220694284b43564c4c32d0ad8e6238594f5cba09a.
Сравнивались также Src/NLui_remake.lua и candy ware/candylib.luau.
По локальным именам нельзя подтвердить происхождение от конкретной платной версии Shitaro.
Авторство исходной библиотеки не приписывается Nix LUA.

Изменения в адаптации:

- убраны загрузки PNG с внешнего GitHub и первоначальная подмена глобального окружения;
- цветовая карта построена из UIGradient, без скачиваемого PNG;
- убраны встроенные конфиги; используется отдельный проверяемый JSON-модуль;
- получение аватара по сети убрано; анимированный фон по умолчанию выключен;
- blur-модуль заменён пустой реализацией, чтобы не оставлять чужие эффекты в Lighting;
- созданные объекты, задачи и соединения сервисов включены в общий механизм очистки;
- ввод текста не переключает меню; запись служебной переменной в getgenv убрана.

Изменения воспроизводятся tools/prepare_mm2.py. Исходные файлы не редактировались.

## Игровые механизмы и визуалы

- Src/yarhm.lua и Src/UpdMM2.lua: структура GetPlayerData, поля Role/Dead/Killed,
  поиск Knife/Gun и объектов GunDrop. Новый адаптер ограничивает частоту запросов,
  не допускает одновременных зависших запросов и не считает неизвестные роли мирными.
- Src/visuals.lua и Src2/visuals.lua: рассмотрены trail, локальная шляпа, цветовые
  эффекты и skybox. Оттуда взяты ID mesh шляпы 1033714 и набор Black Storm.
- Src2/SP_mm2.lua: просмотрены организация визуальных настроек и фильтрация по ролям.
- Src2/aimbot.lua: просмотрен пример выбора цели по экранной проекции.

Игровые модули, настройки, конфиги, загрузчик и управление ресурсами написаны отдельно.
Обфусцированные загрузчики и целые сторонние хабы в проект не включены.
Модели/skybox используют Roblox assets; доступность этих assets проверяется только в игре.
